What is Linux? An operating System

Linux is very crucial in Cybersecurity and has many uses. 

Unlike different OS's like Windows, macOS and Android Linux has different distributions often called "distros" which are different versions. These versions are choosen based on the users needs and preferences.

Linux is generally considered more secure than Windows and other popular OS's due to its frequent updates.

Since it is open-source it can be modified by anyone.

Linux is the most widely installed operating system
